01เชื่อมต่อ Gemini API

ใส่ Gemini API key ของคุณเอง — ค่าเริ่มต้นคือเก็บไว้ในหน่วยความจำของเบราว์เซอร์ระหว่างเซสชันนี้เท่านั้นและจะหายเมื่อรีเฟรช ถ้าไม่อยากพิมพ์ใหม่ทุกครั้ง ให้ติ๊ก "จำ key ไว้ในเครื่องนี้" ด้านล่าง (ไม่แนะนำถ้าใช้เครื่องสาธารณะ/เครื่องที่ใช้ร่วมกับคนอื่น เพราะ key จะถูกเก็บไว้ในเบราว์เซอร์จนกว่าจะล้างเอง)

ยังไม่ได้ทดสอบการเชื่อมต่อ
ข้อมูลในฟอร์ม (เรื่องราว/แนวเพลง/โครงสร้าง/ผลลัพธ์ล่าสุด) จะถูกบันทึกอัตโนมัติ รีเฟรชหน้าแล้วไม่หาย

ยิ่งให้รายละเอียด (ตัวละคร ฉาก อารมณ์ จุดเปลี่ยน) เนื้อเพลงจะยิ่งมีมิติ

ขั้นตอนตั้งแต่ขอ API key ไปจนถึงเอาเนื้อเพลงไปวางใน Suno

01

ขอ Gemini API key ฟรี

ไปที่ aistudio.google.com/apikey ล็อกอินด้วยบัญชี Google แล้วกด "Create API key" คัดลอกรหัสที่ขึ้นต้นด้วย AIza

02

วาง key แล้วทดสอบการเชื่อมต่อ

กลับมาที่แท็บ "แต่งเพลง" วาง key ลงในช่องด้านบนสุด แล้วกด "ทดสอบการเชื่อมต่อ" — ถ้าจุดสถานะเป็นสีเขียวแปลว่าเชื่อมต่อสำเร็จ key จะอยู่ในเบราว์เซอร์ของคุณเท่านั้นและหายไปเมื่อรีเฟรชหน้า

03

ใส่เรื่องราวและทิศทางเพลง

เขียน prompt หรือเรื่องราวที่อยากเล่าให้ละเอียด เลือกแนวเพลงและอารมณ์ได้หลายอัน เลือกภาษาเนื้อเพลง โทนคำ และรูปแบบสัมผัสตามที่ต้องการ

04

จัดโครงสร้างเพลง

ใช้เทมเพลตสำเร็จรูป หรือเพิ่ม/ลบ/สลับลำดับท่อนเอง (Intro, Verse, Chorus, Bridge, Outro ฯลฯ) ลำดับที่จัดไว้จะเป็นลำดับที่ AI แต่งตามเป๊ะๆ

05

กดแต่งเนื้อเพลง

AI จะสร้างชื่อเพลง, style prompt (สำหรับใส่ในช่อง "Style of Music" ของ Suno) และเนื้อเพลงที่มี tag โครงสร้างกำกับให้ครบ

06

คัดลอกไปวางใน Suno

เปิด suno.com → โหมด Custom → วาง "style prompt" ลงช่อง Style of Music และวางเนื้อเพลงทั้งก้อน (พร้อม tag) ลงช่อง Lyrics ได้เลย

07

ปรับแก้เนื้อเพลง

ถ้ายังไม่ถูกใจ ใช้ช่อง "ปรับแก้เนื้อเพลง" ท้ายผลลัพธ์ พิมพ์สิ่งที่อยากแก้ เช่น "ทำท่อน Bridge ให้เศร้ากว่านี้" แล้วกดส่ง AI จะแก้จากเวอร์ชันล่าสุดให้

08

ใช้ตัวช่วยคิดเรื่องราว/โครงสร้าง (ไม่บังคับ)

ถ้ายังไม่มีไอเดีย กดปุ่ม "🎲 สุ่มเรื่องราวทั้งหมด" ให้ AI คิดเรื่องราว แนวเพลง และอารมณ์ให้เลย หรือพิมพ์ไอเดียคร่าวๆ แล้วกด "✨ ช่วยขยายไอเดียนี้" ส่วนโครงสร้างเพลงก็มีปุ่ม "🧩 ให้ AI แนะนำโครงสร้าง" ให้เลือกใช้ได้เช่นกัน

09

สร้าง SRT และคำโปรยยูทูป (ไม่บังคับ)

หลังแต่งเพลงเสร็จในขั้นตอน 05 เลื่อนลงไปที่ขั้นตอน 06 ใส่ความยาวเพลงโดยประมาณเป็นวินาที แล้วกด "🎬 สร้างไฟล์คำบรรยาย SRT" เพื่อดาวน์โหลดไฟล์ .srt สำหรับทำวิดีโอเนื้อเพลง หรือกด "📝 สร้างคำโปรยยูทูป" เพื่อได้ชื่อคลิป คำอธิบาย และแฮชแท็กพร้อมใช้

ความหมายของ tag โครงสร้าง

[Intro]ท่อนเปิดเพลง มักไม่มีเนื้อร้องหรือมีสั้นๆ
[Verse]ท่อนดำเนินเรื่อง เล่ารายละเอียด เนื้อหาต่างกันในแต่ละรอบ
[Pre-Chorus]ท่อนเชื่อมก่อนเข้าท่อนฮุค สร้างอารมณ์ให้พุ่งขึ้น
[Chorus]ท่อนฮุค ใจความหลักของเพลง ซ้ำเดิมทุกรอบ
[Bridge]ท่อนเปลี่ยนบรรยากาศ มักอยู่ก่อนฮุคสุดท้าย
[Outro]ท่อนปิดเพลง
Style promptคำอธิบายแนวเพลง/อารมณ์/เสียงร้อง/เครื่องดนตรีสั้นๆ เป็นภาษาอังกฤษ ใช้กรอกในช่อง Style of Music ของ Suno

คำถามที่พบบ่อย

?

key ของฉันปลอดภัยไหม

หน้านี้เรียก Gemini API ตรงจากเบราว์เซอร์ของคุณไปยัง Google โดยไม่มีเซิร์ฟเวอร์กลาง ค่าเริ่มต้นคือไม่บันทึก key ไว้ที่ใดหลังปิดหรือรีเฟรชหน้า ถ้าติ๊ก "จำ key ไว้ในเครื่องนี้" key จะถูกเก็บไว้ใน localStorage ของเบราว์เซอร์บนอุปกรณ์นี้เท่านั้น ไม่ส่งไปที่อื่น แต่ถ้าใช้เครื่องสาธารณะ/ร่วมกับคนอื่นไม่ควรติ๊กไว้

?

ทำไมข้อมูล/เพลงที่แต่งไว้หายเมื่อรีเฟรช

ปกติแล้วหน้านี้บันทึกฟอร์มและเพลงล่าสุดอัตโนมัติ (autosave) รีเฟรชแล้วไม่ควรหาย — ถ้าหายจริง อาจเป็นเพราะเบราว์เซอร์อยู่ในโหมดส่วนตัว/ไม่รองรับ localStorage หรือมีการกดปุ่ม "ล้างข้อมูลที่บันทึกไว้ทั้งหมด" ไปก่อนหน้า

?

เปิดไฟล์แล้วเชื่อมต่อไม่ได้

เบราว์เซอร์บางตัวจำกัดการยิง request จากไฟล์ที่เปิดตรงๆ (file://) แนะนำให้อัปโหลดไฟล์นี้ขึ้นโฮสต์ฟรี เช่น GitHub Pages หรือ Netlify แล้วเปิดผ่านลิงก์ https แทน

?

ขึ้น error "model not found"

แปลว่าชื่อโมเดลที่ตั้งไว้ในโค้ด (เช่น gemini-3.1-pro-preview) ไม่มีในบัญชีของคุณ ให้เข้า Google AI Studio ดูรายชื่อโมเดลที่ใช้ได้จริง แล้วแก้ค่า PRIMARY_MODEL / ASSIST_MODEL / EXPORT_MODEL ในโค้ดให้ตรงกัน
